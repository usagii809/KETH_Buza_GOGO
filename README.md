# 태형이와 경은이의 부자 되기 프로젝트 💰

둘이 같이 쓰는 가계부 웹앱이에요. 아이폰 홈 화면에 추가해서 앱처럼 써요.

- **주소:** https://usagii809.github.io/buja/
- **기술:** TypeScript · React · Vite · Tailwind CSS · Firebase(로그인, Firestore) · PWA

## 처음 한 번만

1. [Node.js](https://nodejs.org) 22 버전을 설치해요.
2. 이 폴더에서 `npm install`을 실행해요.

## 자주 쓰는 명령

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 내 컴퓨터에서 미리보기 (저장하면 바로 반영) |
| `npm test` | 계산 로직 자동 테스트 |
| `npm run build` | 배포용 파일 만들기 (`dist/`) |

## 배포

`main` 브랜치에 올리면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포까지 자동으로 해요.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 해요.

## 버전

앱 설정(오른쪽 위 프로필 버튼) 맨 아래에 지금 버전이 보여요. 예) **v2.7.40** · 11/26 23:30 배포 · a1b2c3d

| 자리 | 뜻 | 바꾸는 법 |
|---|---|---|
| 첫째 `2` | 큰 변화 (앱을 새로 만들 정도) | `package.json`의 `version`을 `3.0.0`처럼 직접 |
| 둘째 `6` | 기능 묶음 (큰 기능이 들어갔을 때) | `package.json`의 `version`을 `2.7.0`처럼 직접 |
| 셋째 `35` | 배포 번호 | 자동. GitHub Actions 실행 번호(#35)라 올릴 때마다 +1 |

- 셋째 자리는 앞자리를 올려도 0으로 돌아가지 않고 계속 이어져요 (v2.6.40 → v2.7.41). 숫자가 클수록 최신이에요.
- 실패한 배포도 번호를 하나 써서 가끔 숫자가 건너뛰어요.
- 작은 글씨의 7자리(`a1b2c3d`)는 커밋 번호예요. GitHub 커밋 목록과 맞춰보면 어떤 업로드가 반영됐는지 알 수 있어요.
- 배포할 때 `dist/version.json`도 같이 만들어요. 앱이 이걸 보고 더 새 버전이 있으면 설정 화면에 **"새 버전이 있어요 · 지금 업데이트"** 버튼을 띄워요.
- 내 컴퓨터에서 만든 빌드는 `v2.7.dev`로 보여요.
- 새로 올릴 때는 아래 **업데이트 내역** 맨 위에 한 줄씩 더해요.

```

    trend/           지난달 오늘과 비교 · 최근 6개월 지출 그래프
    quips/           지출 페이스별 오늘의 한마디 (문구는 quips.ts에서 추가)
    settings/        설정 · 백업/복원
    auth/            로그인
  data/              Firebase 읽기/쓰기 (db.ts), 실시간 구독 (hooks.ts)
  lib/               카테고리, 날짜, 금액 포맷 같은 공통 도구 + 테스트
  ui/                시트, 토스트, 확인창, 입력칸 같은 공통 부품
  App.tsx            화면 조립
e2e/                 가짜 DB로 화면을 띄워보는 테스트용 설정
worker/              🔔 알림 서버 (Cloudflare Workers에 붙여넣는 파일 하나)
public/push-sw.js    🔔 알림 받기 · 누르면 같이 보기 열기 (서비스 워커)
```

- **새 기능**은 `src/features/`에 폴더를 하나 만들고 `App.tsx`에 붙이면 돼요.
- **돈 계산**은 각 기능의 `calc.ts`에 있고, `src/lib/calc.test.ts`에 테스트가 있어요. 계산을 바꾸면 `npm test`로 확인해 주세요.
- **DB 구조**(`ledgers/shared_household/...`)는 예전 index.html 버전과 같아서 기존 데이터를 그대로 써요.

## 🔔 알림 서버 (Cloudflare Workers)

알림을 보내려면 중간에 서버가 하나 있어야 해서 Cloudflare Workers(무료)를 써요.

1. 앱에서 무언가 하면(기록 · 반응 · 복권 · 쿠폰 · 저축) 앱이 Worker의 `/notify`를 불러요. 이때 Firebase 로그인 토큰을 같이 보내요.
2. Worker는 그 토큰으로 Firestore의 `pushSubs`를 읽어요. 보안 규칙을 통과한 사람만 읽을 수 있어서, 우리 둘이 아니면 알림을 보낼 수 없어요.
3. 보낸 사람 기기와, 그 종류를 꺼둔 기기를 빼고 웹 푸시를 보내요. 없어진 기기는 목록에서 지워요.

- 코드: `worker/push-worker.js` (라이브러리 없이 파일 하나). 고치면 Cloudflare 대시보드에 다시 붙여넣고 Deploy 해주세요.
- Worker 설정값: `FIREBASE_PROJECT_ID` · `VAPID_PUBLIC` · `VAPID_PRIVATE`(Secret) · `VAPID_SUBJECT` · `ALLOWED_ORIGINS`
- 앱 설정값: `src/lib/pushConfig.ts`의 `PUSH_WORKER_URL`(Worker 주소)과 `VAPID_PUBLIC_KEY`(공개키)
- 아이폰은 iOS 16.4 이상, **홈 화면에 추가한 앱**에서만 알림을 받을 수 있어요.

## 기기에만 남는 것 (일부러)

모든 기록과 설정은 Firestore(계정)에 저장돼서 폰 · 웹이 같아요. 기기 안에는 아래만 남아요.

- **알림 켜기/끄기**: 알림 권한과 구독은 폰 · 브라우저마다 따로라 기기별이에요. (어떤 종류를 받을지는 계정에 저장돼서 모든 기기 공통)
- **첫 화면용 사본**: 화면 모드 · 설정을 계정에서 받기 전 첫 화면에 쓰는 사본(`prefsCache`, `themePref`). 계정 값을 받으면 바로 맞춰져요.
- **오프라인 사본**: 인터넷이 없을 때 쓰는 Firestore 자체 저장소. 연결되면 알아서 맞춰져요.
